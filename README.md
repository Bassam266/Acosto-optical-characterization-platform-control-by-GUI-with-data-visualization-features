# Acousto-Optical Characterization Platform — GUI Control and Data Visualization

A graphical user interface (GUI) that controls the acousto-optical characterization platform and provides built-in data visualization.

## Main Features

1. **Instrument communication** — communicates with each instrument.
2. **Instrument integration** — integrates the instruments with one another.
3. **Data acquisition** — acquires the measured data.
4. **Data visualization** — visualizes the measured data.
5. **Sensitivity analysis** — performs sensitivity measurement analysis.
6. **Acoustic/mechanical characterization** — based on the time-of-flight (ToF) method.
