# Acosto-optical characterization platform control by GUI with data visualization features

The GUI has several main purposes:
1. Communicate with the instrument.
2. integrate the instruments with each other.
3. acquire the measured data.
4. visualize the measured data.
3. sensitivity measurement analysis.
4. Acoustic/michanical characterization based on the time-of-flight method
